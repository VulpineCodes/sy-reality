# StreamingAssets/Audio

Drop **your own licensed** audio files here (`.mp3`, `.ogg`, or `.wav`), then set
the song JSON's `audioFile` field to the file name.

Sy-Reality! bundles **no commercial recordings and no copyrighted lyrics**.
The bundled test song ("Twinkle Twinkle Little Star") is public domain and is
timed for the silent / metronome test mode — it works with no audio at all;
adding any lawful recording of the song here will play in sync via the
drift-correcting playback clock.
